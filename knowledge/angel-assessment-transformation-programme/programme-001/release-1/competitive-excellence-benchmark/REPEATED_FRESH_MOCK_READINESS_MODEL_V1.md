# Repeated Fresh Mock Readiness Model V1

**Programme:** Angel Assessment Transformation Execution Programme — Release 1
**Prepared:** 2026-08-11
**Motivated by:** Atom Learning's observed "unlimited fresh practice papers and mock tests" claim — a real competitive pressure point, addressed on evidence, not imitated blindly.

---

## The Core Constraint

Angel's live CSSE question pool is **29 items** (Release 1's own established baseline: 18 original + 11 from migration 016, all currently Provisional/Authentic-Assessment-Candidate status, none Independently Validated). A Full CSSE Mock alone needs ~37-42 scored items. **Angel cannot generate even one fully fresh, non-repeating Full Mock from today's pool, let alone repeated ones.**

## What "Fresh" Must Mean (and Must Not Mean)

- **Must mean:** a genuinely new item, evidence-traced per the Authentic Question Specification, independently reviewed — the same standard every item in this programme has been held to.
- **Must not mean:** superficial variation of an existing item (renamed characters, changed numbers on the same underlying structure) presented as new — this is precisely the "predictable template" and "fabricated difficulty" risk the governing instruction warns against, and precisely what Atom's own marketing claim cannot be taken at face value on without evidence of how they achieve it (NOT VERIFIED in the Benchmark).

## Depth and Diversity Bar, Before "Repeated Fresh Mocks" Is Credible

For one Full Mock's worth of genuine, non-repeating variety at a given Question Type, at minimum **2-3 independently-authored, independently-reviewed items per Question Type** are needed — enough that a second mock can draw a different item for the same slot without it being a cosmetic reskin. Applied across the ~12-16 Question Types a Comprehension section alone touches (per the real evidence range), and the 20-21-question Mathematics range, this implies a pool in the **rough order of 150-250 Independently Validated items** before "generate a genuinely fresh Full Mock on demand" is honestly deliverable — not a precise target, a directional floor, stated explicitly as an estimate, not a validated figure.

**This number is not a commitment or a mass-authoring instruction** — per the governing instruction, no content is authored in this phase. It exists so the gap between "29 provisional items" and "credible unlimited fresh mocks" is visible in real terms, not glossed over.

## Structural Requirements, Not Just Volume

1. **Every item must reach Independently Validated status** (per `RELEASE_1_ASSESSMENT_ELIGIBILITY_MODEL.md`) before entering the "fresh mock" pool — Provisional/Candidate-status items are not fresh-mock-eligible, only practice-eligible at most.
2. **Distribution must match the evidenced Question-Type priority** (Gate 1's tiers) — depth added to already-well-covered types (like the existing pool's QT-MR-01 concentration) does not solve the freshness problem; it worsens the imbalance the Release 1 Gap Analysis already flagged.
3. **A real duplication/near-duplication check** must exist before any item enters rotation — not designed here, flagged as a required component of a future implementation phase.
4. **Difficulty must remain evidence-disclosed, not fabricated to create artificial variety** — the same discipline held throughout Release 1.

## What Angel Can Honestly Offer Today

Per the actual 29-item pool: enough for **one Founder Validation-style slice**, or **Focused Competency Practice** at low volume — not a Full Mock repeated without noticeable repetition. This should be stated to families honestly if any mock product ships before the depth bar above is met, mirroring the disclosure discipline already used on the production Mock's own banner ("this mock is still being expanded").

## Recommendation

Do not promise "unlimited fresh mocks" commercially until the Independently Validated pool genuinely supports it. Track pool depth against the directional floor above as a real, visible metric before any such claim is made — this is a gate, not a target to rush toward by lowering review standards.
