# QT-RC-01 Pilot — Authoring Brief

**Prepared:** 2026-08-10, from the Evidence Pack, before the question was written.
**Step:** 2 of 9. This brief is frozen before Step 3 authoring begins, per instruction.

---

**Capability the item must assess:** locate a single, explicitly-stated fact in a narrative passage and reproduce it accurately, in response to a question stem that narrows the search location.

**What the learner must do cognitively:** read a scoped question, identify the passage region it refers to, find the one stated fact there, write it down (verbatim or lightly paraphrased) — no interpretation, no synthesis of multiple locations, no judgement.

**What information the learner receives:** the full source passage plus a question stem that names a specific character/scene/moment, narrowing where the answer lives.

**Expected reasoning steps:** exactly one (locate → transcribe). Any item requiring a second step (e.g. "why," "what does this suggest") is not QT-RC-01 and must not be authored under this brief.

**Expected response behaviour:** a short, direct, factual answer — a few words to one sentence. Not a list, not a justification, not a quotation-plus-explanation pair.

**Acceptable complexity:** the fact must be explicitly stated somewhere in the passage, not something a reader must infer or construct from multiple details.

**Prohibited shortcuts:** the answer must not be guessable from general knowledge or common sense without reading the passage — it must require genuine passage-location, matching the source evidence's own scoped-stem convention.

**Prohibited forced-fit characteristics:** do not tag an item QT-RC-01 if answering it actually requires inference, evaluative judgement, or synthesising more than one passage location — those belong to other Question Types (RC-02, RC-05, RC-07, etc.) per the Specification, and mis-tagging here would repeat exactly the forced-fit failure mode Gate 2 exists to prevent.

**Originality requirements:** new passage-independent question against an already-existing, already-original Angel passage (not CSSE's own passage or scenario) — no CSSE character name, setting, or plot device may be echoed.

**Authenticity requirements:** the question stem must reproduce the source pattern's defining feature — naming a specific character/scene/moment so the search space is genuinely narrowed, exactly as the CSSE-008 instances do — not a vague, whole-passage-scanning stem.

**Frozen scope decision:** this pilot item will be authored against Angel's own existing "The Lighthouse Mystery" passage (`eng-001`, already live in `ali_question_bank` since migration 013), which currently has zero QT-RC-01 coverage among its four existing questions (`eng-001-q1` through `q4` cover QT-RC-05/QT-RC-03/QT-RC-10/QT-RC-10) — a real, observed gap this pilot item closes, rather than requiring a brand-new passage to be authored as part of this same pilot (passage-writing is a separate skill/scope from question-authoring against the Specification, and conflating the two would make this pilot test two things at once instead of one).
