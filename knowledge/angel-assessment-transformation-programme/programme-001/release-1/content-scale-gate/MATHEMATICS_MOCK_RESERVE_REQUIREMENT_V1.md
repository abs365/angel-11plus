# Mathematics Mock Reserve Requirement V1

**Prepared:** 2026-08-12, Educational Increment 005 Part K.
**Derives from:** `MATHEMATICS_MOCK_SUPPLY_BLUEPRINT_V1.md`'s weighting and `CSSE_FULL_MOCK_STRUCTURE_DECISION_V1.md`'s counted target (20-21 Mathematics questions per sitting). No content authored here.

## Method

A "fresh" mock sitting must not repeat items or families a learner has already seen in a recent sitting (per the Blueprint's unseen-family requirement). For N genuinely fresh sittings, the sealed Mock reserve needs roughly N times the per-sitting requirement, per competency, respecting the Blueprint's weighting — not a flat multiplication, since competencies with a smaller share of the paper need proportionally less reserve.

## Reserve requirement for 3 fresh sittings (a defensible minimum planning horizon, not evidence-derived)

Each competency's reserve should hold enough *distinct families*, each with enough *distinct items*, that 3 sittings can each draw a different family without repeating one. This is a family-count requirement, not just an item-count one — a single family with 18 variants does not satisfy "3 fresh sittings" if a sitting only needs 1-2 items from that competency, because the Blueprint requires unseen *families*, not just unseen exact items.

| Competency | Families needed (≥1 per sitting, 3 sittings) | Items needed (2x sitting requirement per family, 3 families) |
|---|---|---|
| MR-01 | 3 | ~12-18 |
| MR-04 | 3 | ~8-12 |
| MR-02 | 3 | ~6-9 |
| MR-03 | 3 | ~6-9 |
| MR-05 | 2-3 | ~4-6 |

**Total: roughly 20-22 families, 36-54 exact items**, to support 3 genuinely fresh Mathematics mock sittings across the currently-scaled competencies. This is a floor, not the full strategic target — `competitive-excellence-benchmark/REPEATED_FRESH_MOCK_READINESS_MODEL_V1.md`'s own directional 150-250 Independently Validated item figure remains the longer-run destination once more sittings and more competencies (RC/AR/WC) are accounted for.
