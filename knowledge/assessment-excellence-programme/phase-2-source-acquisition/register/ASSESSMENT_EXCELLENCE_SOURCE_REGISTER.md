# Assessment Excellence Source Register

**Purpose:** Lightweight acquisition log — every source candidate identified during Phase 2, its acquisition status, and where it stands before full cataloguing in `ASSESSMENT_EXCELLENCE_EVIDENCE_REGISTER.md`. ## How to read this register

| Column | Meaning |
|---|---|
| ID | Sequential source ID, `AEP2-###` |
| Workstream | Which of the 10 Phase 2 workstreams this source belongs to |
| Title | Working title of the source |
| URL | Verified live URL (or "not found" if the workstream searched and could not locate it) |
| Level | 1 (Official Primary), 2 (Cross-Verified), 3 (Founder Field) per the Founder's Phase 2 instruction |
| Status | Candidate / Verified / Rejected / Superseded |
| Evidence Register Entry | Cross-reference to the full entry once catalogued |
