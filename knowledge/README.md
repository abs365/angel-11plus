# Knowledge Repository

The permanent academic evidence source for Angel 11+. Every pathway's
official source material (past papers, mark schemes, examiner guidance,
writing requirements, and supporting research) lives here, organised by
exam board.

## Structure

```
/knowledge
    /csse
        /official-papers
        /mark-schemes
        /writing
        /examiner-guidance
        /research
```

Future providers follow the same pattern:

```
/knowledge/gl-assessment
/knowledge/cem
/knowledge/iseb
/knowledge/independent
```

## Rules

- Only official source material belongs here — no AI-generated or inferred
  content, no notes copied from third-party websites.
- Any Angel Academic Excellence Programme (AEP) work package that analyses
  exam-board content must cite files under this directory as its source. If
  the relevant subdirectory is empty, that work package is blocked, not
  approximated from general knowledge.
- Do not commit copyrighted material you do not have the right to store and
  distribute. Confirm licensing/usage terms for each document before adding
  it.
