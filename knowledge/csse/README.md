Official source material for the CSSE pathway. AEP-002 (CSSE Examination
Intelligence) reads only from this directory tree — it does not use general
knowledge, live websites, or inference to fill gaps.

|---|---|

| `mark-schemes/` | Official CSSE marking schemes / examiner mark allocations for the papers above. |
| `writing/` | CSSE writing-component task material and assessment criteria. |
| `examiner-guidance/` | Official examiner reports, guidance notes, or moderation standards. |
| `research/` | Supporting research about the CSSE exam (e.g. published admissions guidance) — must still be sourced material, not inference. |
