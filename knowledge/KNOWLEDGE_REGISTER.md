# Knowledge Asset Register

**Angel 11+ — Version 3.0, Academic Excellence Programme**
**Work Package:** KG-002
**Governed by:** `knowledge/KNOWLEDGE_GOVERNANCE.md`

---

## Purpose

This register is the enterprise index of every knowledge asset held in the Knowledge Repository. Every asset added under `knowledge/` must have a corresponding row here, recording the provenance metadata required by `KNOWLEDGE_GOVERNANCE.md` Section 5. An asset present in the repository but absent from this register is not considered part of the governed Knowledge Repository.

## Register Format

Each entry records the following fields, per `KNOWLEDGE_GOVERNANCE.md` Section 5 (Provenance Standard):

| Field | Description |
|---|---|
| **Asset ID** | Unique, permanent identifier for the asset (e.g. `CSSE-OP-001` for a CSSE official paper). Never reused, including after archival. |
| **Provider** | The examination provider the asset relates to (CSSE, GL Assessment, CEM, ISEB, Independent, or Shared). |
| **Title** | A clear, unambiguous name for the asset. |
| **Version** | The edition, series, or version identifier of the source material, where the source itself is versioned. |
| **Evidence Level** | The asset's classification under `KNOWLEDGE_GOVERNANCE.md` Section 4 (A–E). |
| **Source** | The originating body, publication or author, stated precisely enough to be independently verified. |
| **Status** | The asset's current lifecycle stage under `KNOWLEDGE_GOVERNANCE.md` Section 7 (Under Review / Accepted / Superseded / Archived). |
| **Date Added** | The date the asset was added to the Knowledge Repository. |
| **Reviewer** | The individual who reviewed the asset for accuracy of classification and metadata prior to acceptance. |
| **Review Date** | The date the review recorded under Status was completed. |
