# AEI Programme Decisions Register

**Purpose:** Living register of every Programme Decision (`APD-NNN`) issued during the Angel Experience Implementation Programme (AEI), per `AEI-000_EXPERIENCE_IMPLEMENTATION_PROGRAMME_CHARTER.md` §5/§12. Each entry is added in the same commit as the wave work it governs — not reconstructed later.

**Why this exists:** `ACR-001_CONSTITUTIONAL_READINESS_REVIEW.md` found that 11 of the 23 Programme Decisions issued across the IWP-002 Engine Integration Programme (`APD-033` through `APD-055`) were never transcribed into any durable, git-tracked document — issued and acted on in conversation, unrecoverable from the repository alone. This register exists so AEI does not repeat that finding.

**Numbering:** continues sequentially from the last Programme Decision on record (`APD-055`, per `ACR-001`). The next Programme Decision issued during AEI is `APD-056`.
