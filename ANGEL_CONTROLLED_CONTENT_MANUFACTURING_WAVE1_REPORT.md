## B. Why These Families

Selected from the 74 confirmed genuine Maths educational families using live production evidence (real family_ids, row counts, and actual question content fetched read-only before design), not ease of implementation:

- **Curriculum breadth**: covers 5 of the CSSE evidence base's own named domains (arithmetic, algebraic/symbolic reasoning, geometric/spatial reasoning, number theory, percentages) — deliberately not concentrated in geometry alone despite `mr03-angle-sum` already being proven there.
- **Genuine supply gaps**: each new family had only 5-13 practice-eligible rows before this wave (`mr01`=13, `mr02`=5, `mr03-compound`=8, `mr05`=5, `mr04-compound-percentage`=5) — real, meaningful gaps relative to their curriculum importance.
- **Structural diversity headroom confirmed before committing**: real existing content for each family was read live and found to already contain more than one implicit reasoning shape (e.g. `mr01`'s own rows already mix addition/subtraction/multiplication/division-with-remainder; `mr03-compound`'s own rows already include one missing-side-from-perimeter row) — evidence that genuine blueprint diversity was achievable, not manufactured.
- **`mr03-angle-sum` control**: included at a deliberately small allocation (20/220, 9%) to prove the architecture's own consistency across a repeated run, never to dominate the wave.
